# Protolude

## Prérequis

Pour gagner, le joueur incarne un personnage qui doit trouver une épée pour réussir le jeu.

## Interactions requises

- Rammasser la pioche — en entrant en contact avec la pioche, celle-ci disparaît, signifiant que le personnage a rammasser la pioche. Ensuite, il doit se diriger vers l'entrée de la fortification pour aller de l'autre côté.
- Éviter les boules tombantes — plusieurs boules tombent de haut et le joueur doit les eviter.
- Ramasser l'épée — en entrant en contact avec la pioche, celle-ci disparaît, signifiant que le personnage a rammasser la pioche. Ensuite, il doit retourner à l'entrée de la fortification pour réussir le jeu. Il va être transporter dans la scène "Fin".

## Élément pouvant faire échouer le joueur

En touchant les boules qui tombent, le joueur est transporter dans la scène "Game_Over".
